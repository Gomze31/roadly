# Roadly v1 — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer une application Android native « Roadly » installable (APK debug) : carte MapLibre, position et orientation, recherche d'adresses et de POI, favoris, et comparaison de trois itinéraires Valhalla tracés sur la carte.

**Architecture:** Multi-modules Gradle (13 modules) : `core:*` porte les modèles, le design system, les données et les fournisseurs derrière des interfaces Kotlin ; `feature:*` porte les écrans Compose + ViewModels MVVM ; `app` assemble la navigation, le thème et les permissions. Tous les fournisseurs (OpenFreeMap, BAN, Photon, Valhalla) sont gratuits, sans clé, et remplaçables via Hilt.

**Tech Stack:** Kotlin 2.2.10, AGP 8.13.2, Gradle 8.14.3, JDK 21 (cible bytecode 17), Jetpack Compose (BOM 2026.05.00), Material 3, Navigation Compose typée, Hilt 2.60.1 (KSP), Room 2.8.5, DataStore, OkHttp 4.12 + kotlinx.serialization, MapLibre Android 11.13.5, play-services-location, JUnit 4, Turbine, MockWebServer.

**Spec:** `docs/superpowers/specs/2026-10-30-roadly-v1-design.md`

## Global Constraints

- Package racine `fr.roadly` ; nom d'app « Roadly ».
- `minSdk = 29`, `targetSdk = 36`, `compileSdk = 36`.
- Aucune clé API dans le code. Aucune donnée GPS, routière ou tarifaire inventée. Aucun prix carburant par défaut.
- Les `feature:*` dépendent uniquement de `core:*`, jamais d'un autre `feature:*`. `core:model` et `core:common` sont des modules JVM purs (aucune dépendance Android).
- Toute fonction non livrée en v1 est affichée avec `ComingSoonTag` et désactivée ; aucun bouton sans action.
- Textes utilisateur en français dans `res/values/strings.xml` de chaque module.
- Fair-use : en-tête `User-Agent: Roadly/<versionName> (+https://roadly.example)` sur chaque requête, cache HTTP 10 Mo, debounce 300 ms.
- Pas de `git init` (choix utilisateur). Chaque tâche se termine par une vérification de compilation/tests à la place du commit.
- Commande Gradle : toujours `.\gradlew.bat` depuis la racine du projet (`C:\Users\Forza PC\Documents\Yannis\Projet Yannis\GPS`). Les commandes longues (> 2 min) se lancent en arrière-plan.
- Écarts assumés par rapport à la spec : JUnit 4 au lieu de JUnit 5 (intégration AGP sans plugin tiers) ; OkHttp direct au lieu de Retrofit (URL de base dynamiques depuis `ProviderConfig`) ; `Outcome<T>` au lieu de `kotlin.Result<T>` (porte un `AppError` typé).

```kotlin
package fr.roadly.core.model

import kotlinx.serialization.Serializable
import kotlin.math.atan2
import kotlin.math.cos
import kotlin.math.sin
import kotlin.math.sqrt

@Serializable
data class GeoPoint(val lat: Double, val lon: Double) {
    /** Distance orthodromique en mètres (formule de haversine). */
    fun distanceTo(other: GeoPoint): Double {
        val r = 6_371_000.0
        val dLat = Math.toRadians(other.lat - lat)
        val dLon = Math.toRadians(other.lon - lon)
        val a = sin(dLat / 2) * sin(dLat / 2) +
            cos(Math.toRadians(lat)) * cos(Math.toRadians(other.lat)) * sin(dLon / 2) * sin(dLon / 2)
        return 2 * r * atan2(sqrt(a), sqrt(1 - a))
    }
}

@Serializable
data class BoundingBox(val south: Double, val west: Double, val north: Double, val east: Double) {
    companion object {
        fun of(points: List<GeoPoint>): BoundingBox? {
            if (points.isEmpty()) return null
            return BoundingBox(
                south = points.minOf { it.lat }, west = points.minOf { it.lon },
                north = points.maxOf { it.lat }, east = points.maxOf { it.lon },
            )
        }
    }
}
```

```kotlin
sealed interface Outcome<out T> {
    data class Success<T>(val value: T) : Outcome<T>
    data class Failure(val error: AppError) : Outcome<Nothing>
}

inline fun <T, R> Outcome<T>.map(transform: (T) -> R): Outcome<R> = when (this) {
    is Outcome.Success -> Outcome.Success(transform(value))
    is Outcome.Failure -> this
}

inline fun <T, R> Outcome<T>.flatMap(transform: (T) -> Outcome<R>): Outcome<R> = when (this) {
    is Outcome.Success -> transform(value)
    is Outcome.Failure -> this
}

fun <T> Outcome<T>.getOrNull(): T? = (this as? Outcome.Success)?.value
fun <T> Outcome<T>.errorOrNull(): AppError? = (this as? Outcome.Failure)?.error
```

```kotlin
import java.util.Locale

object Formatters {
    private val fr = Locale.FRANCE
    private val clock = DateTimeFormatter.ofPattern("HH:mm")

    fun distance(meters: Double): String = when {
        meters < 1000 -> "${(meters / 10).roundToInt() * 10} m"
        meters < 10_000 -> String.format(fr, "%.1f km", meters / 1000)
        else -> "${(meters / 1000).roundToInt()} km"
    }

    fun duration(seconds: Double): String {
        val totalMin = (seconds / 60).roundToInt()
        val h = totalMin / 60
        val m = totalMin % 60
        return if (h == 0) "$m min" else "$h h ${m.toString().padStart(2, '0')}"
    }

    fun euros(amount: Double): String = String.format(fr, "%.2f €", amount)

    fun clockTime(epochMs: Long, zone: ZoneId = ZoneId.systemDefault()): String =
        clock.format(Instant.ofEpochMilli(epochMs).atZone(zone))
```

`SunTimes.kt` :
```kotlin
package fr.roadly.core.common

import kotlin.math.asin
import kotlin.math.atan2
import kotlin.math.cos
import kotlin.math.sin

/** Élévation solaire approchée (algorithme NOAA simplifié, précision < 1°), suffisant pour le thème automatique. */
object SunTimes {
    fun isNight(lat: Double, lon: Double, epochMs: Long): Boolean = solarElevationDegrees(lat, lon, epochMs) < -0.833

    fun solarElevationDegrees(lat: Double, lon: Double, epochMs: Long): Double {
        val jd = epochMs / 86_400_000.0 + 2_440_587.5
        val n = jd - 2_451_545.0
        val meanLong = (280.460 + 0.9856474 * n).mod(360.0)
        val meanAnom = Math.toRadians((357.528 + 0.9856003 * n).mod(360.0))
        val eclLong = Math.toRadians(meanLong + 1.915 * sin(meanAnom) + 0.020 * sin(2 * meanAnom))
        val obliq = Math.toRadians(23.439 - 0.0000004 * n)
        val ra = atan2(cos(obliq) * sin(eclLong), cos(eclLong))
        val dec = asin(sin(obliq) * sin(eclLong))
        val gmstHours = (18.697374558 + 24.06570982441908 * n).mod(24.0)
        val lst = Math.toRadians((gmstHours * 15 + lon).mod(360.0))
        val hourAngle = lst - ra
        val latR = Math.toRadians(lat)
        val sinElev = sin(latR) * sin(dec) + cos(latR) * cos(dec) * cos(hourAngle)
        return Math.toDegrees(asin(sinElev.coerceIn(-1.0, 1.0)))
    }
}
```

```kotlin
package fr.roadly.core.data.network

import fr.roadly.core.common.AppError
import fr.roadly.core.common.DispatcherProvider
import fr.roadly.core.common.Outcome
import kotlinx.coroutines.suspendCancellableCoroutine
import kotlinx.coroutines.withContext
import okhttp3.Call
import okhttp3.Callback
import okhttp3.HttpUrl
import okhttp3.MediaType.Companion.toMediaType
import okhttp3.OkHttpClient
import okhttp3.Request
import okhttp3.RequestBody.Companion.toRequestBody
import okhttp3.Response
import java.io.IOException
import java.net.SocketTimeoutException
import javax.inject.Inject
import javax.inject.Singleton
import kotlin.coroutines.resume
import kotlin.coroutines.resumeWithException

@Singleton
class ApiClient @Inject constructor(
    private val client: OkHttpClient,
    private val dispatchers: DispatcherProvider,
) {
    suspend fun get(url: HttpUrl): Outcome<String> = execute(Request.Builder().url(url).get().build())

    suspend fun postJson(url: HttpUrl, body: String): Outcome<String> = execute(
        Request.Builder().url(url).post(body.toRequestBody("application/json; charset=utf-8".toMediaType())).build(),
    )

    private suspend fun execute(request: Request): Outcome<String> = withContext(dispatchers.io) {
        try {
            client.newCall(request).await().use { resp ->
                val text = resp.body?.string().orEmpty()
                when {
                    resp.isSuccessful -> Outcome.Success(text)
                    resp.code == 429 -> Outcome.Failure(AppError.RateLimited)
                    resp.code in 500..599 -> Outcome.Failure(AppError.ProviderUnavailable(request.url.host, resp.code))
                    else -> Outcome.Failure(AppError.Http(resp.code, text))
                }
            }
        } catch (e: SocketTimeoutException) {
            Outcome.Failure(AppError.Timeout)
        } catch (e: IOException) {
            Outcome.Failure(AppError.Network)
        }
    }
}

private suspend fun Call.await(): Response = suspendCancellableCoroutine { cont ->
    enqueue(object : Callback {
        override fun onResponse(call: Call, response: Response) { cont.resume(response) }
        override fun onFailure(call: Call, e: IOException) { if (!cont.isCancelled) cont.resumeWithException(e) }
    })
    cont.invokeOnCancellation { cancel() }
}
```

```kotlin
    suspend fun toggle(place: Place)
    suspend fun setHome(place: Place)

@Singleton
class RoomFavoritesRepository @Inject constructor(private val dao: FavoriteDao) : FavoritesRepository {
    override fun observeAll() = dao.observeAll().map { list -> list.map { it.toPlace() } }
    override fun observeHome() = dao.observeHome().map { it?.toPlace() }
    override fun observeWork() = dao.observeWork().map { it?.toPlace() }
    override suspend fun isFavorite(id: String) = dao.byId(id) != null
    override suspend fun toggle(place: Place) {
        val existing = dao.byId(place.id)
        when {
            existing == null -> dao.upsert(place.toEntity())
            !existing.isHome && !existing.isWork -> dao.delete(place.id)
            else -> Unit // domicile/travail : on ne retire pas via le favori
        }
    }
    override suspend fun setHome(place: Place) = dao.setHome(dao.byId(place.id) ?: place.toEntity())
    override suspend fun setWork(place: Place) = dao.setWork(dao.byId(place.id) ?: place.toEntity())
    override suspend fun clear() = dao.clear()
}
```

```kotlin
            ?.hasCapability(NetworkCapabilities.NET_CAPABILITY_VALIDATED) == true
        val cb = object : ConnectivityManager.NetworkCallback() {
            override fun onAvailable(network: Network) { trySend(true) }
            override fun onLost(network: Network) { trySend(current()) }
            override fun onCapabilitiesChanged(network: Network, caps: NetworkCapabilities) {
                trySend(caps.hasCapability(NetworkCapabilities.NET_CAPABILITY_VALIDATED))
            }
        }
        trySend(current())
        cm.registerNetworkCallback(NetworkRequest.Builder().addCapability(NetworkCapabilities.NET_CAPABILITY_INTERNET).build(), cb)
        awaitClose { cm.unregisterNetworkCallback(cb) }
    }.distinctUntilChanged()
}
```

```kotlin
package fr.roadly.core.geocoding

import fr.roadly.core.model.GeoPoint

object CoordinateParser {
    private val decimal = Regex("""^\s*(-?\d{1,2}(?:[.,]\d+)?)\s*[,; ]\s*(-?\d{1,3}(?:[.,]\d+)?)\s*$""")
    private val dms = Regex(
        """^\s*(\d{1,2})[°\s]\s*(\d{1,2})['′\s]\s*(?:(\d{1,2}(?:[.,]\d+)?)["″\s])?\s*([NS])\s*[,;]?\s*(\d{1,3})[°\s]\s*(\d{1,2})['′\s]\s*(?:(\d{1,2}(?:[.,]\d+)?)["″\s])?\s*([EWO])\s*$""",
        RegexOption.IGNORE_CASE,
    )

    fun parse(input: String): GeoPoint? {
        decimal.matchEntire(input)?.let { m ->
            return valid(m.groupValues[1].replace(',', '.').toDouble(), m.groupValues[2].replace(',', '.').toDouble())
        }
        dms.matchEntire(input)?.let { m ->
            val lat = toDecimal(m.groupValues[1], m.groupValues[2], m.groupValues[3]) * if (m.groupValues[4].equals("S", true)) -1 else 1
            val lonSign = if (m.groupValues[8].uppercase() in setOf("W", "O")) -1 else 1
            val lon = toDecimal(m.groupValues[5], m.groupValues[6], m.groupValues[7]) * lonSign
            return valid(lat, lon)
        }
        return null
    }

    private fun toDecimal(d: String, m: String, s: String): Double =
        d.toDouble() + m.toDouble() / 60 + (s.takeIf { it.isNotEmpty() }?.replace(',', '.')?.toDouble() ?: 0.0) / 3600

    private fun valid(lat: Double, lon: Double): GeoPoint? =
        if (lat in -90.0..90.0 && lon in -180.0..180.0) GeoPoint(lat, lon) else null
}
```

```kotlin
class BanGeocodingProvider @Inject constructor(

    private val config: ProviderConfigRepository,
    private val json: Json,

    override val id = "ban"

    override suspend fun search(query: String, near: GeoPoint?, limit: Int): Outcome<List<Place>> {
        val base = config.config.first().banBaseUrl
        val url = "$base/search/".toHttpUrl().newBuilder()

            .addQueryParameter("limit", limit.toString())
            .apply { if (near != null) { addQueryParameter("lat", near.lat.toString()); addQueryParameter("lon", near.lon.toString()) } }
            .build()
        return api.get(url).flatMap { parse(it) }
    }

    override suspend fun reverse(point: GeoPoint): Outcome<Place?> {
        val base = config.config.first().banBaseUrl
        val url = "$base/reverse/".toHttpUrl().newBuilder()
            .addQueryParameter("lon", point.lon.toString())
            .addQueryParameter("lat", point.lat.toString())
            .build()
        return api.get(url).flatMap { parse(it) }.let { r -> when (r) { is Outcome.Success -> Outcome.Success(r.value.firstOrNull()); is Outcome.Failure -> r } }
    }

    private fun parse(body: String): Outcome<List<Place>> = try {
        val fc = json.decodeFromString(BanFeatureCollection.serializer(), body)
        Outcome.Success(fc.features.mapNotNull { f ->
            val coords = f.geometry?.coordinates ?: return@mapNotNull null
            if (coords.size < 2) return@mapNotNull null
            val p = f.properties
            val kind = when (p.type) { "housenumber" -> PlaceKind.ADDRESS; "street", "locality" -> PlaceKind.STREET; "municipality" -> PlaceKind.CITY; else -> PlaceKind.ADDRESS }
            val name = if (kind == PlaceKind.CITY) (p.city ?: p.label.orEmpty()) else (p.name ?: p.label.orEmpty())
            val address = listOfNotNull(p.postcode, p.city).joinToString(" ").ifBlank { null }
            Place(id = "ban:${p.id ?: "${coords[1]},${coords[0]}"}", name = name, address = address, point = GeoPoint(coords[1], coords[0]), kind = kind, source = id)
        })
    } catch (e: Exception) {
        Outcome.Failure(AppError.Parse(e.message ?: "ban"))
    }
}
```

```kotlin
/** BAN d'abord (adresses France), Photon ensuite (POI, villes, Europe). Fusion, déduplication, repli. */
@Singleton
class CompositeGeocoder @Inject constructor(
    @BanGeocoder private val ban: GeocodingProvider,
    @PhotonGeocoder private val photon: GeocodingProvider,
) : GeocodingProvider {
    override val id = "composite"

    override suspend fun search(query: String, near: GeoPoint?, limit: Int): Outcome<List<Place>> {
        val coord = CoordinateParser.parse(query)
        if (coord != null) {
            return Outcome.Success(listOf(Place("coord:${coord.lat},${coord.lon}", "Coordonnées GPS", "%.5f, %.5f".format(java.util.Locale.ROOT, coord.lat, coord.lon), coord, PlaceKind.COORDINATES, "local")))
        }
        val (banR, photonR) = coroutineScope {
            val a = async { ban.search(query, near, limit) }
            val b = async { photon.search(query, near, limit) }
            a.await() to b.await()
        }
        val merged = mutableListOf<Place>()
        fun addAll(r: Outcome<List<Place>>) {
            if (r is Outcome.Success) r.value.forEach { p -> if (merged.none { it.isSameAs(p) }) merged += p }
        }
        addAll(banR); addAll(photonR)
        return when {
            merged.isNotEmpty() -> Outcome.Success(merged.take(limit))
            banR is Outcome.Failure && photonR is Outcome.Failure -> Outcome.Failure(AppError.ProviderUnavailable("géocodage"))
            else -> Outcome.Success(emptyList())
        }
    }

    override suspend fun reverse(point: GeoPoint): Outcome<Place?> {
        val r = ban.reverse(point)
        if (r is Outcome.Success && r.value != null) return r
        return photon.reverse(point)
    }

    private fun Place.isSameAs(o: Place): Boolean = point.distanceTo(o.point) < 30.0 && name.normalized() == o.name.normalized()
    private fun String.normalized() = Normalizer.normalize(lowercase(), Normalizer.Form.NFD).replace(Regex("\\p{M}+"), "").replace(Regex("[^a-z0-9]+"), " ").trim()
}
```

```kotlin
package fr.roadly.core.routing

import fr.roadly.core.model.GeoPoint

/** Décodage polyline (algorithme Google) ; Valhalla encode avec une précision 1e6. */
object Polyline6 {
    fun decode(encoded: String, precision: Double = 1e6): List<GeoPoint> {
        val out = ArrayList<GeoPoint>(encoded.length / 4 + 1)
        var index = 0; var lat = 0; var lon = 0
        while (index < encoded.length) {
            var result = 0; var shift = 0; var b: Int
            do { b = encoded[index++].code - 63; result = result or ((b and 0x1f) shl shift); shift += 5 } while (b >= 0x20)
            lat += if (result and 1 != 0) (result shr 1).inv() else result shr 1
            result = 0; shift = 0
            do { b = encoded[index++].code - 63; result = result or ((b and 0x1f) shl shift); shift += 5 } while (b >= 0x20)
            lon += if (result and 1 != 0) (result shr 1).inv() else result shr 1
            out += GeoPoint(lat / precision, lon / precision)
        }
        return out
    }
}
```

```kotlin
/** Valhalla — https://valhalla.github.io/valhalla/api/turn-by-turn/api-reference/ . Instance publique FOSSGIS en dev ; auto-hébergée en prod. */
@Singleton
class ValhallaRoutingProvider @Inject constructor(
    private val api: ApiClient,
    private val config: ProviderConfigRepository,
    private val json: Json,
) : RoutingProvider {
    override val id = "valhalla"

    override suspend fun route(request: RouteRequest): Outcome<List<Route>> {
        val base = config.config.first().valhallaBaseUrl
        val body = buildJsonObject {
            putJsonArray("locations") {
                (listOf(request.origin) + request.waypoints + request.destination).forEach { p -> addJsonObject { put("lat", p.lat); put("lon", p.lon) } }
            }
            put("costing", "auto")
            putJsonObject("costing_options") {
                putJsonObject("auto") {
                    when (request.costing) {
                        RouteCosting.FASTEST -> Unit
                        RouteCosting.SHORTEST -> put("shortest", true)
                        RouteCosting.NO_TOLL -> put("use_tolls", 0)
                    }
                }
            }
            put("units", "kilometers")
            put("language", "fr-FR")
        }
        return when (val r = api.postJson("$base/route".toHttpUrl(), body.toString())) {
            is Outcome.Success -> parse(r.value, request.costing)
            is Outcome.Failure -> Outcome.Failure(mapError(r.error))
        }
    }

    private fun mapError(e: AppError): AppError {
        if (e is AppError.Http && e.code == 400) {
            val code = runCatching { json.decodeFromString(ValhallaError.serializer(), e.body).errorCode }.getOrNull()
            // 171 = pas d'arête proche, 442 = pas de chemin : résultat vide, pas une panne.
            if (code == 171 || code == 442 || code == 170) return AppError.NoResult
        }
        return e
    }

    private fun parse(body: String, costing: RouteCosting): Outcome<List<Route>> = try {
        val trip = json.decodeFromString(ValhallaResponse.serializer(), body).trip
        val geometry = ArrayList<GeoPoint>()
        val maneuvers = ArrayList<Maneuver>()
        trip.legs.forEach { leg ->
            val pts = Polyline6.decode(leg.shape)
            val offset = if (geometry.isEmpty()) 0 else geometry.size - 1
            if (geometry.isNotEmpty() && pts.isNotEmpty()) geometry.addAll(pts.drop(1)) else geometry.addAll(pts)
            leg.maneuvers.forEach { m ->
                maneuvers += Maneuver(
                    type = mapType(m.type),
                    instruction = m.instruction,
                    streetName = m.streetNames.firstOrNull(),
                    lengthMeters = m.length * 1000.0,
                    durationSeconds = m.time,
                    beginShapeIndex = offset + m.beginShapeIndex,
                    roundaboutExit = m.roundaboutExitCount,
                )
            }
        }
        if (geometry.isEmpty()) Outcome.Failure(AppError.NoResult) else Outcome.Success(listOf(
            Route(
                id = UUID.randomUUID().toString(),
                costing = costing,
                distanceMeters = trip.summary.length * 1000.0,
                durationSeconds = trip.summary.time,
                geometry = geometry,
                maneuvers = maneuvers,
                hasToll = trip.summary.hasToll || trip.legs.any { l -> l.maneuvers.any { it.toll } },
                providerId = id,
            ),
        ))
    } catch (e: Exception) {
        Outcome.Failure(AppError.Parse(e.message ?: "valhalla"))
    }

    internal fun mapType(t: Int): ManeuverType = when (t) {
        1, 2, 3 -> ManeuverType.DEPART
        4, 5, 6 -> ManeuverType.ARRIVE
        7, 8 -> ManeuverType.CONTINUE
        9 -> ManeuverType.SLIGHT_RIGHT
        10 -> ManeuverType.TURN_RIGHT
        11 -> ManeuverType.SHARP_RIGHT
        12, 13 -> ManeuverType.UTURN
        14 -> ManeuverType.SHARP_LEFT
        15 -> ManeuverType.TURN_LEFT
        16 -> ManeuverType.SLIGHT_LEFT
        17, 18, 19 -> ManeuverType.RAMP
        20, 21 -> ManeuverType.EXIT
        22 -> ManeuverType.CONTINUE
        23 -> ManeuverType.KEEP_RIGHT
        24 -> ManeuverType.KEEP_LEFT
        25, 37, 38 -> ManeuverType.MERGE
        26 -> ManeuverType.ROUNDABOUT_ENTER
        27 -> ManeuverType.ROUNDABOUT_EXIT
        28, 29 -> ManeuverType.FERRY
        else -> ManeuverType.OTHER
    }
}
```

```kotlin
package fr.roadly.core.routing

import fr.roadly.core.common.AppError
import fr.roadly.core.common.Outcome

import fr.roadly.core.model.GeoPoint
import fr.roadly.core.model.Route
```

```kotlin
import fr.roadly.core.model.VehicleProfile
import kotlinx.coroutines.async
import kotlinx.coroutines.coroutineScope
import javax.inject.Inject

data class RouteOption(
    val route: Route,
    val label: String,
    val arrivalEpochMs: Long,
    val cost: CostEstimate?,
    val sameAsFastest: Boolean,
)

class RouteAlternativesUseCase @Inject constructor(private val routing: RoutingProvider) {
    private val order = listOf(RouteCosting.FASTEST, RouteCosting.SHORTEST, RouteCosting.NO_TOLL)

    suspend operator fun invoke(origin: GeoPoint, destination: GeoPoint, vehicle: VehicleProfile?, departAtEpochMs: Long): Outcome<List<RouteOption>> {
        val results = coroutineScope {
            order.map { c -> async { c to routing.route(RouteRequest(origin, destination, costing = c, vehicle = vehicle, departAtEpochMs = departAtEpochMs)) } }.map { it.await() }
        }
        val routes = results.mapNotNull { (c, r) -> (r as? Outcome.Success)?.value?.firstOrNull()?.copy(costing = c) }
        if (routes.isEmpty()) {
            val firstError = results.firstNotNullOfOrNull { (_, r) -> (r as? Outcome.Failure)?.error } ?: AppError.NoResult
            return Outcome.Failure(firstError)
        }
        val fastest = routes.firstOrNull { it.costing == RouteCosting.FASTEST }
        return Outcome.Success(routes.map { r ->
            RouteOption(
                route = r,
                label = r.costing.label(),
                arrivalEpochMs = departAtEpochMs + (r.durationSeconds * 1000).toLong(),
                cost = vehicle?.let { FuelCostCalculator.estimate(r.distanceMeters, it) },
                sameAsFastest = fastest != null && r.costing != RouteCosting.FASTEST && r.geometry == fastest.geometry,
            )
        })
```

```kotlin
import kotlinx.coroutines.flow.callbackFlow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.emptyFlow
import kotlinx.coroutines.flow.flatMapLatest
import kotlinx.coroutines.flow.onEach
import kotlinx.coroutines.flow.shareIn
import javax.inject.Inject
import javax.inject.Singleton

@OptIn(ExperimentalCoroutinesApi::class)
@Singleton
class FusedLocationRepository @Inject constructor(
    @ApplicationContext private val ctx: Context,
    @ApplicationScope scope: CoroutineScope,
) : LocationRepository {
    private val fused = LocationServices.getFusedLocationProviderClient(ctx)
    private val mode = MutableStateFlow(LocationMode.OFF)
    private val _permission = MutableStateFlow(readPermission())
    override val permissionState: StateFlow<LocationPermissionState> = _permission

    @Volatile override var lastKnown: LocationFix? = null
        private set

    override val fixes: Flow<LocationFix> = combine(mode, _permission) { m, p -> if (p == LocationPermissionState.GRANTED) m else LocationMode.OFF }
        .flatMapLatest { m -> if (m == LocationMode.OFF) emptyFlow() else updates(m) }
        .onEach { lastKnown = it }
        .shareIn(scope, SharingStarted.WhileSubscribed(stopTimeoutMillis = 5_000), replay = 1)

    @SuppressLint("MissingPermission")
    private fun updates(m: LocationMode): Flow<LocationFix> = callbackFlow {
        fused.lastLocation.addOnSuccessListener { loc -> if (loc != null) trySend(loc.toFix()) }
        val request = LocationRequest.Builder(Priority.PRIORITY_HIGH_ACCURACY, m.intervalMs)
            .setMinUpdateIntervalMillis(m.intervalMs / 2)
            .setWaitForAccurateLocation(false)
            .build()
        val callback = object : LocationCallback() {
            override fun onLocationResult(result: LocationResult) { result.lastLocation?.let { trySend(it.toFix()) } }
        }
        fused.requestLocationUpdates(request, callback, Looper.getMainLooper())
        awaitClose { fused.removeLocationUpdates(callback) }
    }

    override fun setMode(mode: LocationMode) { this.mode.value = mode }

    override fun refreshPermission() { _permission.value = readPermission() }

    override fun markDeniedForever() { _permission.value = LocationPermissionState.DENIED_FOREVER }

    private fun readPermission(): LocationPermissionState {
        val fine = ContextCompat.checkSelfPermission(ctx, Manifest.permission.ACCESS_FINE_LOCATION) == PackageManager.PERMISSION_GRANTED
        val coarse = ContextCompat.checkSelfPermission(ctx, Manifest.permission.ACCESS_COARSE_LOCATION) == PackageManager.PERMISSION_GRANTED
        return when {
            fine || coarse -> LocationPermissionState.GRANTED
            _permissionInitialized -> LocationPermissionState.DENIED
            else -> LocationPermissionState.UNKNOWN
        }.also { _permissionInitialized = true }
    }
    private var _permissionInitialized = false

    private fun android.location.Location.toFix() = LocationFix(
        point = GeoPoint(latitude, longitude),
        bearingDeg = if (hasBearing()) bearing else null,
        speedMps = if (hasSpeed()) speed else null,
        accuracyM = if (hasAccuracy()) accuracy else 50f,
        timestampMs = time,
    )
}
```

```kotlin
/** GeoJSON FeatureCollection des tracés ; l'itinéraire actif est placé en dernier (dessiné au-dessus). */
object RouteFeatureBuilder {
    fun build(routes: List<Route>, activeId: String?): String {
        val ordered = routes.filter { it.id != activeId } + routes.filter { it.id == activeId }
        return buildJsonObject {
            put("type", "FeatureCollection")
            putJsonArray("features") {
                ordered.forEach { r ->
                    add(buildJsonObject {
                        put("type", "Feature")
                        putJsonObject("properties") { put("id", r.id); put("active", r.id == activeId) }
                        putJsonObject("geometry") {
                            put("type", "LineString")
                            put("coordinates", JsonArray(r.geometry.map { p -> JsonArray(listOf(JsonPrimitive(p.lon), JsonPrimitive(p.lat))) }))
                        }
                    })
                }
            }
        }.toString()
    }
}

internal object PointFeatureBuilder {
    fun user(fix: LocationFix): String = buildJsonObject {
        put("type", "Feature")
        putJsonObject("properties") { put("bearing", (fix.bearingDeg ?: 0f).toDouble()); put("accuracy", fix.accuracyM.toDouble()) }
        putJsonObject("geometry") { put("type", "Point"); put("coordinates", JsonArray(listOf(JsonPrimitive(fix.point.lon), JsonPrimitive(fix.point.lat)))) }
    }.toString()

    fun markers(places: List<Place>): String = buildJsonObject {
        put("type", "FeatureCollection")
        putJsonArray("features") {
            places.forEach { p ->
                add(buildJsonObject {
                    put("type", "Feature")
                    putJsonObject("properties") { put("id", p.id); put("name", p.name) }
                    putJsonObject("geometry") { put("type", "Point"); put("coordinates", JsonArray(listOf(JsonPrimitive(p.point.lon), JsonPrimitive(p.point.lat)))) }
                })
            }
        }
```

```kotlin
/**
 * Pont entre l'état Compose et la MapLibreMap. Toutes les commandes reçues avant que le style soit prêt
 * sont mémorisées et rejouées (`replayState`), y compris après un changement de style clair/sombre.

class MapController(private val context: Context) {
    private var map: MapLibreMap? = null
    private var styleReady = false
    private var currentStyleUrl: String? = null

    private var lastFix: LocationFix? = null
    private var lastRoutes: List<Route> = emptyList()
    private var lastActiveRouteId: String? = null
    private var lastMarkers: List<Place> = emptyList()
    private var routeColorActive = "#4FD1E0"
    private var routeColorInactive = "#5B6774"

    var onRouteClick: ((String) -> Unit)? = null

    internal fun attach(map: MapLibreMap) {
        this.map = map
        map.uiSettings.isCompassEnabled = false
        map.uiSettings.isAttributionEnabled = true
        map.uiSettings.isLogoEnabled = false
        map.uiSettings.isRotateGesturesEnabled = true
        map.uiSettings.isTiltGesturesEnabled = false
        map.addOnMapClickListener { latLng ->
            val m = this.map ?: return@addOnMapClickListener false
            val pt = m.projection.toScreenLocation(latLng)
            val hit = m.queryRenderedFeatures(pt, MapIds.LYR_ROUTE_INACTIVE, MapIds.LYR_ROUTE_ACTIVE).firstOrNull()
            val id = hit?.getStringProperty("id")
            if (id != null) { onRouteClick?.invoke(id); true } else false
        }
        currentStyleUrl?.let { loadStyle(it) }
    }

    fun setRouteColors(active: String, inactive: String) { routeColorActive = active; routeColorInactive = inactive; if (styleReady) replayState() }

    fun setStyle(url: String) {
        if (url == currentStyleUrl && styleReady) return
        currentStyleUrl = url
        if (map != null) loadStyle(url)
    }

    private fun loadStyle(url: String) {
        styleReady = false
        map?.setStyle(Style.Builder().fromUri(url)) { style -> installLayers(style); styleReady = true; replayState() }
    }

    private fun installLayers(style: Style) {
        style.addImage(MapIds.IMG_ARROW, drawableToBitmap(R.drawable.ic_user_arrow))
        style.addImage(MapIds.IMG_PIN, drawableToBitmap(R.drawable.ic_place_pin))

            lineColor(routeColorActive), lineWidth(6f), lineCap(Property.LINE_CAP_ROUND), lineJoin(Property.LINE_JOIN_ROUND),

    private fun replayState() {
        val style = map?.style ?: return
        lastFix?.let { style.getSourceAs<GeoJsonSource>(MapIds.SRC_USER)?.setGeoJson(PointFeatureBuilder.user(it)) }
        style.getSourceAs<GeoJsonSource>(MapIds.SRC_ROUTES)?.setGeoJson(RouteFeatureBuilder.build(lastRoutes, lastActiveRouteId))
        style.getSourceAs<GeoJsonSource>(MapIds.SRC_MARKERS)?.setGeoJson(PointFeatureBuilder.markers(lastMarkers))
        (style.getLayer(MapIds.LYR_ROUTE_ACTIVE) as? LineLayer)?.setProperties(lineColor(routeColorActive))
        (style.getLayer(MapIds.LYR_ROUTE_INACTIVE) as? LineLayer)?.setProperties(lineColor(routeColorInactive))
    }

    fun setUserLocation(fix: LocationFix?) {
        lastFix = fix
        if (!styleReady) return
        val src = map?.style?.getSourceAs<GeoJsonSource>(MapIds.SRC_USER) ?: return
        if (fix == null) src.setGeoJson("""{"type":"FeatureCollection","features":[]}""") else src.setGeoJson(PointFeatureBuilder.user(fix))
    }

    fun setRoutes(routes: List<Route>, activeId: String?) {
        lastRoutes = routes; lastActiveRouteId = activeId
        if (styleReady) map?.style?.getSourceAs<GeoJsonSource>(MapIds.SRC_ROUTES)?.setGeoJson(RouteFeatureBuilder.build(routes, activeId))
    }

    fun setMarkers(places: List<Place>) {
        lastMarkers = places
        if (styleReady) map?.style?.getSourceAs<GeoJsonSource>(MapIds.SRC_MARKERS)?.setGeoJson(PointFeatureBuilder.markers(places))
    }

    fun moveTo(point: GeoPoint, zoom: Double, bearing: Double = 0.0, animate: Boolean = true) {
        val m = map ?: return
        val pos = CameraPosition.Builder().target(LatLng(point.lat, point.lon)).zoom(zoom).bearing(bearing).tilt(0.0).build()
        val update = CameraUpdateFactory.newCameraPosition(pos)
        if (animate) m.animateCamera(update, 600) else m.moveCamera(update)
    }

    fun fitBounds(points: List<GeoPoint>, paddingPx: Int) {
        val m = map ?: return
        val bbox = BoundingBox.of(points) ?: return
        if (bbox.north == bbox.south && bbox.east == bbox.west) { moveTo(points.first(), 15.0); return }
        val bounds = LatLngBounds.Builder().include(LatLng(bbox.south, bbox.west)).include(LatLng(bbox.north, bbox.east)).build()
        m.animateCamera(CameraUpdateFactory.newLatLngBounds(bounds, paddingPx), 600)
    }

    fun applyCameraMode(mode: CameraMode, fix: LocationFix?) {
        if (fix == null) return
        when (mode) {
            CameraMode.FREE -> Unit
            CameraMode.CENTERED -> moveTo(fix.point, 15.5, bearing = 0.0)
            CameraMode.FOLLOW -> moveTo(fix.point, 17.0, bearing = (fix.bearingDeg ?: 0f).toDouble())
        }
    }

    private fun drawableToBitmap(resId: Int): Bitmap {
        val d = ContextCompat.getDrawable(context, resId)!!
        val bmp = Bitmap.createBitmap(d.intrinsicWidth.coerceAtLeast(1), d.intrinsicHeight.coerceAtLeast(1), Bitmap.Config.ARGB_8888)
        val c = Canvas(bmp); d.setBounds(0, 0, c.width, c.height); d.draw(c)
        return bmp
    }
}
```

```kotlin
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import dagger.hilt.android.lifecycle.HiltViewModel
import fr.roadly.core.common.AppError
import fr.roadly.core.common.Outcome

import fr.roadly.core.data.repository.FavoritesRepository
import fr.roadly.core.data.repository.RecentSearchRepository
import fr.roadly.core.geocoding.GeocodingProvider
import fr.roadly.core.location.LocationRepository
import fr.roadly.core.model.Place
import kotlinx.coroutines.ExperimentalCoroutinesApi
import kotlinx.coroutines.FlowPreview
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.debounce
import kotlinx.coroutines.flow.distinctUntilChanged
import kotlinx.coroutines.flow.flatMapLatest
import kotlinx.coroutines.flow.flow
import kotlinx.coroutines.flow.stateIn
import kotlinx.coroutines.launch
import javax.inject.Inject

@OptIn(FlowPreview::class, ExperimentalCoroutinesApi::class)
@HiltViewModel
class SearchViewModel @Inject constructor(
    private val geocoder: GeocodingProvider,
    private val recents: RecentSearchRepository,
    private val favorites: FavoritesRepository,
    private val location: LocationRepository,
    connectivity: ConnectivityObserver,
) : ViewModel() {

    private val query = MutableStateFlow("")
    private val selected = MutableStateFlow<Place?>(null)
    private val selectedIsFavorite = MutableStateFlow(false)
    private val online = connectivity.isOnline.stateIn(viewModelScope, SharingStarted.Eagerly, true)

    private val results = query
        .debounce(300)
        .distinctUntilChanged()
        .flatMapLatest { q -> searchFlow(q.trim()) }

    val uiState: StateFlow<SearchUiState> = combine(
        query, results, recents.observe(), favorites.observeAll(), online, selected, selectedIsFavorite,
    ) { values ->
        @Suppress("UNCHECKED_CAST")
        SearchUiState(
            query = values[0] as String,
            results = values[1] as SearchResults,
            recents = values[2] as List<Place>,
            favorites = values[3] as List<Place>,
            isOnline = values[4] as Boolean,
            selected = values[5] as Place?,
            selectedIsFavorite = values[6] as Boolean,
        )
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), SearchUiState())

    private fun searchFlow(q: String) = flow {
        if (q.length < 2) { emit(SearchResults.Idle); return@flow }
        if (!online.value) { emit(SearchResults.Error(AppError.Network)); return@flow }
        emit(SearchResults.Loading)
        when (val r = geocoder.search(q, location.lastKnown?.point)) {
            is Outcome.Success -> emit(SearchResults.Content(r.value))
            is Outcome.Failure -> emit(SearchResults.Error(r.error))
        }
    }

    fun onQueryChange(value: String) { query.value = value }

    fun onClear() { query.value = "" }

    fun retry() { val q = query.value; query.value = ""; query.value = q }

    fun onPlaceSelected(place: Place) {
        selected.value = place
        viewModelScope.launch {
            recents.record(place)
            selectedIsFavorite.value = favorites.isFavorite(place.id)
        }
    }

    fun onDismissPlace() { selected.value = null }

    fun onToggleFavorite() {
        val p = selected.value ?: return
        viewModelScope.launch { favorites.toggle(p); selectedIsFavorite.value = favorites.isFavorite(p.id) }
    }

    fun onSetHome() { val p = selected.value ?: return; viewModelScope.launch { favorites.setHome(p); selectedIsFavorite.value = true } }
    fun onSetWork() { val p = selected.value ?: return; viewModelScope.launch { favorites.setWork(p); selectedIsFavorite.value = true } }
}
```

```kotlin
import kotlinx.coroutines.flow.combine

import kotlinx.coroutines.flow.onStart
import kotlinx.coroutines.flow.stateIn
import kotlinx.coroutines.launch
import javax.inject.Inject

@HiltViewModel
class HomeViewModel @Inject constructor(
    private val location: LocationRepository,
    favorites: FavoritesRepository,
    private val geocoder: GeocodingProvider,
    connectivity: ConnectivityObserver,
    config: ProviderConfigRepository,
) : ViewModel() {

    private val cameraMode = MutableStateFlow(CameraMode.CENTERED)
    private val address = MutableStateFlow<String?>(null)
    private val picked = MutableStateFlow<Place?>(null)
    private val isDark = MutableStateFlow(true)
    private var lastReversePoint: GeoPoint? = null
    private var reverseJob: Job? = null

    private val fixes = location.fixes
        .onStart { location.setMode(if (cameraMode.value == CameraMode.FOLLOW) LocationMode.FOLLOW else LocationMode.MAP) }
        .onEach { maybeReverse(it) }
        .onCompletion { location.setMode(LocationMode.OFF) }

    val uiState: StateFlow<HomeUiState> = combine(
        fixes.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), null),
        address, favorites.observeHome(), favorites.observeWork(), cameraMode,
        location.permissionState, connectivity.isOnline, config.config, picked, isDark,
    ) { values ->
        val cfg = values[7] as fr.roadly.core.data.config.ProviderConfig
        HomeUiState(
            fix = values[0] as LocationFix?,
            address = values[1] as String?,
            home = values[2] as Place?,
            work = values[3] as Place?,
            cameraMode = values[4] as CameraMode,
            permission = values[5] as fr.roadly.core.location.LocationPermissionState,
            isOnline = values[6] as Boolean,
            styleUrl = if (values[9] as Boolean) cfg.mapStyleDarkUrl else cfg.mapStyleLightUrl,
            pickedPlace = values[8] as Place?,
        )
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), HomeUiState())

    private fun maybeReverse(fix: LocationFix) {
        val last = lastReversePoint
        if (last != null && last.distanceTo(fix.point) < 50.0) return
        lastReversePoint = fix.point
        reverseJob?.cancel()
        reverseJob = viewModelScope.launch {
            when (val r = geocoder.reverse(fix.point)) {
                is Outcome.Success -> address.value = r.value?.let { listOfNotNull(it.name, it.address).joinToString(", ") }
                is Outcome.Failure -> Unit // on garde la dernière adresse connue
            }
        }
    }

    fun setDarkTheme(dark: Boolean) { isDark.value = dark }

    fun onUserGesture() { if (cameraMode.value != CameraMode.FREE) { cameraMode.value = CameraMode.FREE; location.setMode(LocationMode.MAP) } }

    /** FREE → CENTERED → FOLLOW → CENTERED … */
    fun onRecenter() {
        cameraMode.value = when (cameraMode.value) {
            CameraMode.FREE -> CameraMode.CENTERED
            CameraMode.CENTERED -> CameraMode.FOLLOW
            CameraMode.FOLLOW -> CameraMode.CENTERED
        }
        location.setMode(if (cameraMode.value == CameraMode.FOLLOW) LocationMode.FOLLOW else LocationMode.MAP)
    }

    fun onPermissionResult() { location.refreshPermission() }
    fun onPermissionDeniedForever() { location.markDeniedForever() }

    /** Appui long sur la carte : propose ce point comme destination. */
    fun onMapLongClick(point: GeoPoint) {
        picked.value = Place("pick:${point.lat},${point.lon}", "Point sur la carte", "%.5f, %.5f".format(java.util.Locale.ROOT, point.lat, point.lon), point, PlaceKind.COORDINATES, "local")
        viewModelScope.launch {
            val r = geocoder.reverse(point)
            if (r is Outcome.Success && r.value != null) picked.value = r.value!!.copy(id = "pick:${point.lat},${point.lon}")
        }
    }

    fun onDismissPicked() { picked.value = null }
}
```

```kotlin
package fr.roadly.feature.route

import androidx.lifecycle.SavedStateHandle
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import androidx.navigation.toRoute
import dagger.hilt.android.lifecycle.HiltViewModel
import fr.roadly.core.common.Outcome
import fr.roadly.core.data.config.ProviderConfigRepository
import fr.roadly.core.data.repository.VehicleProfileRepository
import fr.roadly.core.location.LocationRepository
import fr.roadly.core.model.GeoPoint
import fr.roadly.core.routing.RouteAlternativesUseCase
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.flow.stateIn
import kotlinx.coroutines.launch
import javax.inject.Inject

@HiltViewModel
class RouteViewModel @Inject constructor(
    savedStateHandle: SavedStateHandle,
    private val alternatives: RouteAlternativesUseCase,
    private val vehicleRepo: VehicleProfileRepository,
    private val location: LocationRepository,
    private val config: ProviderConfigRepository,
) : ViewModel() {

    private val args = savedStateHandle.toRoute<RouteRoute>()
    private val destination = GeoPoint(args.destLat, args.destLon)
    private val origin = MutableStateFlow(location.lastKnown?.point)
    private val departAt = MutableStateFlow(System.currentTimeMillis())
    private val activeId = MutableStateFlow<String?>(null)
    private val isDark = MutableStateFlow(true)
    private val computed = MutableStateFlow<RouteUiState>(RouteUiState.Loading)
    private val reload = MutableStateFlow(0)

    init {
        viewModelScope.launch {
            combine(origin, departAt, vehicleRepo.profile, reload) { o, d, v, _ -> Triple(o, d, v) }.collect { (o, d, v) ->
                if (o == null) { computed.value = RouteUiState.NoOrigin(args.destName); return@collect }
                computed.value = RouteUiState.Loading
                val cfg = config.config.first()
                when (val r = alternatives(o, destination, v, d)) {
                    is Outcome.Success -> {
                        val options = r.value
                        if (activeId.value == null || options.none { it.route.id == activeId.value }) activeId.value = options.first().route.id
                        computed.value = RouteUiState.Content(o, args.destName, options, activeId.value!!, v != null, d, if (isDark.value) cfg.mapStyleDarkUrl else cfg.mapStyleLightUrl)
                    }
                    is Outcome.Failure -> computed.value = RouteUiState.Error(r.error)
                }
            }
        }
    }

    val uiState: StateFlow<RouteUiState> = combine(computed, activeId, isDark, config.config) { s, id, dark, cfg ->
        if (s is RouteUiState.Content) s.copy(activeId = id ?: s.activeId, styleUrl = if (dark) cfg.mapStyleDarkUrl else cfg.mapStyleLightUrl) else s
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), RouteUiState.Loading)

    fun setDarkTheme(dark: Boolean) { isDark.value = dark }
    fun selectRoute(id: String) { activeId.value = id }
    fun setDepartAt(epochMs: Long) { departAt.value = epochMs }
    fun retry() { reload.value++ }
    /** Origine choisie par appui long sur la carte quand la position est inconnue. */
    fun setOrigin(point: GeoPoint) { origin.value = point }
    val destinationPoint: GeoPoint get() = destination
}
```

```kotlin
package fr.roadly.app

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import dagger.hilt.android.lifecycle.HiltViewModel
import fr.roadly.core.common.SunTimes
import fr.roadly.core.data.repository.ThemeMode
import fr.roadly.core.data.repository.UserPreferencesRepository
import fr.roadly.core.location.LocationRepository
import kotlinx.coroutines.delay
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.flow
import kotlinx.coroutines.flow.stateIn
import java.time.Instant
import java.time.ZoneId
import javax.inject.Inject

object ThemeResolver {
    fun isDark(mode: ThemeMode, systemDark: Boolean, lat: Double?, lon: Double?, nowMs: Long): Boolean = when (mode) {
        ThemeMode.SYSTEM -> systemDark
        ThemeMode.LIGHT -> false
        ThemeMode.DARK -> true
        ThemeMode.AUTO_SOLAR -> if (lat != null && lon != null) SunTimes.isNight(lat, lon, nowMs) else {
            val h = Instant.ofEpochMilli(nowMs).atZone(ZoneId.systemDefault()).hour
            h < 7 || h >= 20
        }
    }
}

@HiltViewModel
class ThemeViewModel @Inject constructor(prefs: UserPreferencesRepository, private val location: LocationRepository) : ViewModel() {
    private val tick = flow { while (true) { emit(System.currentTimeMillis()); delay(60_000) } }
    val themeMode: StateFlow<ThemeMode> = prefs.themeMode.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), ThemeMode.AUTO_SOLAR)
    val solarNight: StateFlow<Boolean?> = combine(themeMode, tick) { mode, now ->
        if (mode != ThemeMode.AUTO_SOLAR) null else {
            val p = location.lastKnown?.point
            ThemeResolver.isDark(mode, systemDark = false, lat = p?.lat, lon = p?.lon, nowMs = now)
        }
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), null)
}
```

```kotlin
package fr.roadly.app

import android.Manifest
import android.content.Intent
import android.net.Uri
import android.os.Bundle
import android.provider.Settings
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.activity.enableEdgeToEdge
import androidx.activity.result.contract.ActivityResultContracts
import androidx.activity.viewModels
import androidx.compose.foundation.isSystemInDarkTheme
import androidx.compose.runtime.getValue
import androidx.core.app.ActivityCompat
import androidx.lifecycle.compose.collectAsStateWithLifecycle
import dagger.hilt.android.AndroidEntryPoint
import fr.roadly.core.data.repository.ThemeMode
import fr.roadly.core.designsystem.theme.RoadlyTheme
import fr.roadly.core.location.LocationRepository
import fr.roadly.core.location.PermissionEvents
import javax.inject.Inject

@AndroidEntryPoint
class MainActivity : ComponentActivity() {
    @Inject lateinit var location: LocationRepository
    @Inject lateinit var permissionEvents: PermissionEvents
    private val themeVm: ThemeViewModel by viewModels()

    private val permissionLauncher = registerForActivityResult(ActivityResultContracts.RequestMultiplePermissions()) { result ->
        val granted = result[Manifest.permission.ACCESS_FINE_LOCATION] == true || result[Manifest.permission.ACCESS_COARSE_LOCATION] == true
        if (!granted && !ActivityCompat.shouldShowRequestPermissionRationale(this, Manifest.permission.ACCESS_FINE_LOCATION)) location.markDeniedForever() else location.refreshPermission()
        permissionEvents.changed.tryEmit(Unit)
    }

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            val mode by themeVm.themeMode.collectAsStateWithLifecycle()
            val solarNight by themeVm.solarNight.collectAsStateWithLifecycle()
            val systemDark = isSystemInDarkTheme()
            val isDark = when (mode) {
                ThemeMode.SYSTEM -> systemDark
                ThemeMode.LIGHT -> false
                ThemeMode.DARK -> true
                ThemeMode.AUTO_SOLAR -> solarNight ?: systemDark
            }
            RoadlyTheme(darkTheme = isDark) {
                RoadlyNavHost(
                    isDark = isDark,
                    onRequestLocationPermission = { permissionLauncher.launch(arrayOf(Manifest.permission.ACCESS_FINE_LOCATION, Manifest.permission.ACCESS_COARSE_LOCATION)) },
                    onOpenAppSettings = { startActivity(Intent(Settings.ACTION_APPLICATION_DETAILS_SETTINGS, Uri.fromParts("package", packageName, null))) },
                )
            }
        }
    }

    override fun onResume() { super.onResume(); location.refreshPermission(); permissionEvents.changed.tryEmit(Unit) }
}
```
